# Module 5 — SQL Labs

Use this folder for the two PostgreSQL and Supabase live labs. Follow Brightspace for when to begin each activity and for any submission instructions.

## Learning path

1. **Review Lesson 5A:** Read [Lesson 5A SQL Live Lab](Module-5A-SQL-Live-Lab.md) to revisit how we created tables, inserted a small dataset, and wrote first queries. Its CREATE TABLE and INSERT statements are for a fresh setup; do not rerun them in a project where those tables already exist.
2. **Prepare for Lesson 5B:** Read [Module 5 Database Setup](Module-5-Database-Setup.md), then run the complete [reset and seed SQL script](Module-5-Reset-and-Seed.sql) in your CSCI 362 practice Supabase project. It removes and rebuilds `public.clubs` and `public.events`, replacing the Lesson 5A data with 6 clubs and 24 events.
3. **Complete Lesson 5B:** Open [Lesson 5B SQL Live Lab](Module-5B-SQL-Live-Lab.md). Start with the verified 6-club, 24-event database. The lab changes and deletes some rows, so do not rerun the reset script after you begin.

> [!IMPORTANT]
> The reset script deletes any existing data in these two practice tables. Check your Supabase project before running it. Use fictional course data only; keep credentials and real student information out of the SQL Editor and shared work.

Keep the [SQL Vocabulary and Fundamentals Guide](../SQL-Vocabulary-Guide.md) and [SQL Quick Reference](../SQL-Quick-Reference.md) nearby for explanations and syntax patterns.
